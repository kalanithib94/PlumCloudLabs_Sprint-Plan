How it works — Jira → CSV → brain dump → plan
Full technical user guide (CSV mapping modal + every field):
  1. Pick your team tab above (Dev, Marketing, EE, Hynoyo). Plans save separately in this browser.
  2. Fill sprint dates and check the team roster. Adjust leave days and alloc % if needed.
  3. Import CSV from Jira (sticky bar). Map columns — use Assignee-V2, not the manager-echo Assignee column.
  4. Brain dump any rearrangements (shared JIRAs, splits, removals) in plain English — see format below.
  5. Copy Cursor prompt → paste into Cursor chat → Paste JSON from Cursor in the sticky bar.
  6. Save and Download HTML for the release plan. Use Import HTML later to edit and re-download.

Step 1 — Ask ROVO in Jira (exact prompt)

In Jira, open ROVO and paste this. Change the epic name for your sprint (example uses EE).

List all child items of the epic "EE Sprint 04" as a table with these columns: Key, Summary, Type, Status, Priority, Assignee, Reporter, Due Date, Created, Updated, Assignee-V2, Co-Assignee-V2, Story Point Estimate

Export the table ROVO returns as CSV, then use Import CSV in the sticky bar.

Step 2 — Brain dump format (after CSV import)

One change per line or paragraph. Use JIRA keys. Say shared vs personal, hours per person, and what to remove from someone’s list.

V2-8748 Review Test Scripts is shared, not personal.
Split 64h between Piyush Pandey (24h) and Ramesh Mandava (40h).

V2-8749 — Vusion Hypercare
Split 30h equally between Jeevan and kalanithi
Remove V2-8748 from Piyush's personal list.

Then click Copy Cursor prompt on the Brain dump card (includes your plan + these notes) → paste into Cursor → apply the JSON it returns.
